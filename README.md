Struct-to-Dict Program in Python

Description

This repository contains a Python program that creates a student record using namedtuple and converts the record into a dictionary.

The program uses the collections module and the _asdict() method to perform the conversion.

How to Run

1. Make sure Python is installed on your computer.
2. Download the struct-to-dict.py file.
3. Run the file using Python.
4. View the student record displayed in the output.

Example Output

Student Record:
{'name': 'Vikram', 'age': 19, 'course': 'CSE AI-ML'}

Learning Objective

To understand named tuples, dictionaries, and converting structured data into dictionary format in Python.
